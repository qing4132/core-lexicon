# 物象词锚与母语表达全景手册 · 总目录（Core Image Lexicon & Native Expression Atlas）

> **核心理念与编排说明**：
> - **【唯一物理原型】**：跳过传统词典里零散罗列的七八个孤立中文义项，每个词只抓最底层的 **1 个实物切面、力学动作或空间画面**，帮助学习者直接建立英语画面感与语感直觉。
> - **【同类与近义辨析】**：将同一生活场景（如同一超市货架、同一张菜单、同一类医疗症状）或最易混淆的近义词并排对比，一次理清使用边界，避免查词时无休止地发散跳转。
> - **全库规模**：共 **19 册正文（约 9,000 行）**，包含 **505 个核心词锚（横向拓展覆盖 2,200+ 个高频实用词与近义词组）** + **20 大真实场景、200 条“中文表达需求 → 自然地道英文表达”**。

## 推荐使用方式

1. **每天阅读 1 册（或半册，约 25 个核心词锚）+ 1 个场景（10 条实用表达）**：
   - 阅读词锚时，先看 **【唯一物理原型】**，在脑海里建立起那个实物切面或动作画面；
   - 接着结合 **【同类与近义辨析】**，把同一场景下的几个关联词在画面上区分清楚，再通过 **【例句】** 体会实际语境。
2. **用第 18、19 册进行“看中文说英文”主动练习**：
   - 在阅读 **[18 · 平实母语级表达直通车（上）](./18-平实母语级表达直通车-上.md)** 和 **[19 · 平实母语级表达直通车（下）](./19-平实母语级表达直通车-下.md)** 时，可以先只看第一行 **【表达需求】** 的中文，尝试自己开口用英文表达；
   - 然后再对照下一行 **【地道表达】** 与 **【核心搭配与解析】**，将加粗的核心语块（Chunks）熟读掌握。
